# 유사 문제 생성 지연 개선 기록

2026-11-08 사용자 제공 처리 기록에서는 분류1.632초, 원문 확보0.001초(이미지 캐시 적중), 생성15.241초 후 검수가1.071초에서 취소됐다. 전체18초 한도 안에 완료하지 못했다. 검수가 정상 종료되는 데 필요한 시간은 이 기록으로 알 수 없다. 중첩된 노드와 모델 호출 시간은 합산하지 않는다.

## 반영한 변경

- 일반 독해 지문은120~180단어를 목표로 하되 원문 유형·난이도·필요한 근거를 우선하도록 지시했다. 짧은 안내문 등은 자연스러운 유형별 길이를 따른다. 이는 프롬프트의 목표이며 강제 자르기가 아니다.
- 정답 근거와 각 오답 이유는 유지하면서 번역·도입·맺음말·중복 설명을 생략하도록 했다.
- 독립 검수는 유지하고, 승인/거절 결과의 reason만 간결하게 출력하도록 했다.
- SDK가 반환한 reasoning_tokens를 사용량 기록에 추가하고, 화면/표 CSV에서 input_tokens·output_tokens·reasoning_tokens를 확인할 수 있게 했다. 추론 내용 자체는 기록하지 않는다. 사용량이 없거나 호출이 취소되면 값이 비어 있을 수 있다. 출력 토큰 수는 추론 토큰을 포함하므로 둘을 합산하지 않는다.

모델 정책, 추론 강도, 출력 토큰 상한, 독립 검수, 수정 루프, 전체18초 마감은 유지했다. 프롬프트 변경만으로 실제 지연 개선이나 정확도 동등성이 입증되는 것은 아니다. 이 변경 이후에는 이전 저장소와 프롬프트·진단 표시가 달라진다.

## 검증과 다음 측정

회귀 테스트70개를 통과했다. SDK 모의 응답의 토큰 사용량 추출과 Streamlit 진단 표 표시도 확인했다. 실제 API 키를 읽거나 유료 호출을 실행하지 않았다.

실제 API로 같은 생성 요청을3회 실행하고 매번 답변 전체가 완성되는지, 원문 유형·난이도와 정답 유일성·해설 타당성이 유지되는지 확인한다. 각 실행의 전체 처리 시간, 모델, 분류/생성/검수 시간과 토큰 사용량을 기록한다. 이미지 캐시 미적중과 적중 조건을 구분한다. 시간 초과나 검수 실패는 성공으로 집계하지 않는다. 반복3회는 개발 확인 절차이며 최종평가의 공식 반복 횟수를 의미하지 않는다.

여전히 느리다면 실측 결과에 따라 생성/검수의 추론 강도와 모델 후보를 한 번에 하나씩 비교한다. 작은 모델로의 임의 전환이나 검수 생략으로 해결하지 않는다. 검수를 기다리는 UI 스트리밍은 답변 전체 완료 기준을 충족시키지 않는다.
