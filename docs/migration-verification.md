# 이전 전후 동작 대조

2026-11-08. AI가 기존 portfolio-lab 앱과 FinalProject의 두 실행 환경을 비교했다. 앱 코드는 수정하지 않았다.

| 검증 | 결과 |
| --- | --- |
| 실행 코드·테스트·설정26개 파일 | 바이트 내용 동일 |
| FinalProject 독립 환경 테스트 |70개 통과 |
| 실제 자료의 파싱 결과 전체 | 두 환경의 정규화 JSON 해시 일치 |
| 실제 자료의 채점 결과 전체 | 두 환경의 정규화 JSON 해시 일치 |
| 결과 엑셀 다섯 시트 전체 셀 값 | 두 환경의 정규화 JSON 해시 일치 |
| 통계/최저점·학생 자기소개 조회·정보 부재 모의 대화 | 답변·상태·모델 호출 수 일치 |

실제 자료는 학생10명·문항45개다. 원본 학생 정보·정답·배점·전체 답변은 비교 과정의 메모리에서만 다뤘으며 보고서에 복사하지 않았다. 엑셀 ZIP의 생성시각 메타데이터나 실행 소요시간을 바이트 동일성 대상으로 삼지 않았다.

초기 비교 스크립트는 기본 샌드박스 실행에서 응답이 지연되어 이번 스크립트의 프로세스만 종료하고, 자동 테스트와 같은 승인 실행 조건으로 재검증했다. 두 비교 실행은 정상 종료했다.

이는 확인한 코드/자료/모의 대화의 동일성 검증이다. 실제 OpenAI 키 조회·유료 호출·두 브라우저의 실 모델 응답 비교·배포/20초 검증은 하지 않았다. 확률적인 실제 모델의 문장/생성 문제/소요시간이 매번 동일하다고 보장하지 않는다.

수동 API 확인 질문은 [테스트질문8개](테스트질문_8개.txt)를 사용한다. 질문 파일은 런타임에서 읽지 않으며 예상 정답을 앱에 주입하지 않는다. 외부 API 실행 결과는 정확도와 전체 완료시간을 별도로 기록해야 한다.
